# Szakdolgozat - Jövőbeli Funkció- és Architektúra Ötletek

Ez a dokumentum tartalmazza a szakdolgozati alkalmazás elrendezési, architektúrábeli és jövőbeli funkció-ötleteit.

## 1. Architektúra & Felhasználókezelési Döntés
- **Eszközök & Környezet:** Közös adathordozók (tabletek) az üzemben / raktárban.
- **Konzisztens Szerepkör Modell:**
  - **`WORKER` (Dolgozó):** Automatikus / közös bejelentkezés a tableteken. Szkennelésre, cérna/anyag keresésre és PDF tervrajzok megtekintésére használják. Nem szükséges személyes login, így nincs szükség egyéni olvasottsági visszaigazolásra sem.
  - **`ADMIN` / `SHIFT_MANAGER` (Admin / Műszakvezető):** Külön jogosultsággal rendelkező fiók. Kezeli a kategóriákat, anyagokat, PDF dokumentumokat és a faliújság hirdetményeit.

---

## 2. Jövőbeli Funkció Ötletek (Szakdolgozati Bővítéshez)

### A) Üzemi Üzenőfal / Faliújság Modul (Notice Board)
- **Cél:** A műszakvezető vagy adminisztrátor fontos tájékoztatásokat tehet közzé az üzemben lévő tabletekre.
- **Működés:**
  - Időalapú megjelenítés (pl. 24 óráig vagy műszak végéig érvényes).
  - Prioritási szintek (pl. Sürgős / Kiemelt / Tájékoztató).
  - Színkódolt vizuális megjelenítés az app főoldalán.

### B) Belső Üzenő / Hibabejelentő Modul (Messaging / Ticket System)
- **Cél:** Gyors jelzés küldése a műszakvezetők / vezetők felé az alkalmazáson belül.
- **Működés:**
  - Gyors gomb az anyagnál vagy PDF-nél (pl. "Hiányzó cérna jelzése" vagy "Hibás rajz jelzése").
  - Műszakvezetők és vezetők közötti belső üzenetváltás.

## 3. Oracle DB Kibővített Séma Terv

```sql
-- 1. Felhasználói szerepkörök és userek (Admin, ShiftManager, Worker)
CREATE TABLE USERS (
    ID NUMBER GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    USERNAME VARCHAR2(50) NOT NULL UNIQUE,
    PASSWORD_HASH VARCHAR2(255) NOT NULL,
    ROLE VARCHAR2(20) CHECK (ROLE IN ('ADMIN', 'SHIFT_MANAGER', 'WORKER')),
    FULL_NAME VARCHAR2(100)
);

-- 2. Üzenőfal / Hirdetmények
CREATE TABLE ANNOUNCEMENTS (
    ID NUMBER GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    AUTHOR_ID NUMBER REFERENCES USERS(ID),
    TITLE VARCHAR2(200) NOT NULL,
    CONTENT CLOB NOT NULL,
    PRIORITY VARCHAR2(20) DEFAULT 'NORMAL' CHECK (PRIORITY IN ('LOW', 'NORMAL', 'HIGH', 'URGENT')),
    CREATED_AT TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    EXPIRES_AT TIMESTAMP
);

-- 3. Belső üzenetek / Hibabejelentések
CREATE TABLE MESSAGES (
    ID NUMBER GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    SENDER_ID NUMBER REFERENCES USERS(ID),
    RECEIVER_ID NUMBER REFERENCES USERS(ID),
    SUBJECT VARCHAR2(200),
    MESSAGE_TEXT CLOB NOT NULL,
    SENT_AT TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    IS_READ NUMBER(1) DEFAULT 0 CHECK (IS_READ IN (0, 1))
);
```
